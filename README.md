# 중학교 수학 자료집 문항 선택 (협의용 모형)

인천 AI 논·서술형 평가 자료집 제출 문항 3세트(정비례·반비례, 피타고라스 정리, 대푯값)를 한 화면에서 골라 보며, 채점 기준표·예시 답안·채점 시 유의점·채점 사례·평가 개요를 확인하는 교과 협의용 페이지입니다. 실제 평가지원시스템이 아닙니다.

- 주소 뒤에 #세트-문항-창 을 붙이면 바로 열립니다. 예: #nb-3-rub (대푯값 1-3 채점 기준표), #pt-1-ans, #jb-2-case, #nb-1-cmp (세 세트 비교)
- 세트: jb 정비례·반비례, pt 피타고라스, nb 대푯값 / 창: rub 채점 기준표, ans 예시 답안, cau 유의점, case 채점 사례, ov 평가 개요
